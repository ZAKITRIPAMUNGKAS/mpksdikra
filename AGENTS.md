# Instruksi Proyek Arqam

Semua agent wajib membaca dokumen ini sebelum bekerja, lalu membaca:
- `docs/agentic/PRD.md`
- `docs/agentic/RULES.md`
- `docs/agentic/MEMORY.md`
- `docs/agentic/DEBUG-RULES.md` saat debug, bug fix, atau verifikasi

Dokumen tersebut adalah konteks wajib. Jika konflik dengan permintaan pengguna terbaru, minta klarifikasi bila konflik memengaruhi data, keamanan, aturan nilai, atau scope.

Jangan mengedit `D:\website\SKRIPSI\SISTEM`. Itu proyek referensi read-only.

Mulai semua pekerjaan dengan membaca struktur proyek dan kode terkait. Terapkan perubahan minimum. Jalankan perintah verifikasi tersedia. Perbarui `docs/agentic/MEMORY.md` bila keputusan permanen berubah.
